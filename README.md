# SECURE CODING REVIEW

A Python-based secure login management system developed to demonstrate secure coding practices and security vulnerability mitigation. This project focuses on identifying and preventing common security issues such as SQL Injection, weak password usage, plaintext password storage, and unsafe input handling.

The application includes secure user registration, login authentication, password hashing using SHA-256, strong password validation, and secure database operations using parameterized SQL queries. The project helps in understanding secure authentication mechanisms, database security, and best practices for developing safer applications.

## TECHNOLOGIES USED

* Python
* SQLite Database
* Hashlib
* Regular Expressions (re)

## SECURITY FEATURES

* Password Hashing
* SQL Injection Prevention
* Strong Password Validation
* Secure Authentication
* Input Validation
* Secure Database Queries
